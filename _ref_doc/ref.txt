基于 VexRiscv 的智能应用平台吴文豪、赵子勋、陈柯帆第一部分 设计概述1.1 设计目的VexRiscv 是一个由 SpinalHDL 开发的轻量级、高性能的 RISC-V 架构处理器。利用 FPGA 的可编程性，本小组在高云 Tang Mega 138K Pro Dock 上成功移植并实现了基于 VexRiscv 的 SoC 应用平台，具备 UART、SPI、IIC 等多个外设，并基于此做出了多样化的应用。本小组的作品为了适用于多场景应用，分为了单核嵌入式裸机开发和多核嵌入式 Linux 开发这两个方向进行应用开发，积极探索出基于 RISC-V 架构处理器在嵌入式领域多样化的应用，旨在为芯片全面国产化之路做出一点贡献。1.2 应用领域本小组基于 VexRiscv CPU 构建的智能应用平台可以作为一个通用计算机处理平台，分为单核裸机开发和多核 Linux 开发，可以适用于多种应用场景，特别是在资源受限的嵌入式系统和需要高性能计算的领域。在嵌入式系统开发中，由于 RISC-V 架构处理器的轻量低功耗的特点，VexRiscv CPU 可以广泛应用于智能穿戴设备中；在高性能计算领域，可以通过启用 FPU 和高速缓存等高级功能来构建多核系统，使 VexRiscv CPU 可以用于需要较高计算性能的应用，可以用于在车载系统中进行实时控制系统或数据处理任务；在教育与研究领域中，由于其开源性质和详细的文档使得 VexRiscV CPU 成为学习和研究 RISC-V 架构及计算机体系结构的理想选择。/图 1 应用场景示意图1.3 主要技术特点搭载 VexRiscv CPU 核心，支持 RV32IMA 系统。通过先进的一致性接口规范实现核心间的高效通信和数据管理，支持多级缓存一致性和无缓存代理操作。该架构允许每个核心独立执行指令并共享资源，同时通过 BMB(Bus Matrix Bridge)优化核心间通信和内存访问。一致性接口规范一致性接口规范是系统设计的核心，它由三个主要接口组成：读写接口和探测接口，共包含七个流。这些接口支持双数据路径，允许脏/干净数据共享，并提供屏障同步以保证无序执行中的内存操作顺序。内存副本状态的管理内存副本状态的管理包括有效/无效、共享/唯一、所有者/寄宿者以及干净/脏等状态，以确保数据一致性和系统稳定性。事务处理机制事务处理机制主要定义了在一致性接口上移动的事务，包括读取命令、读取响应、写入命令、写入响应、探测命令和探测响应。这些事务确保了内存操作的正确性，并允许系统在多核环境下维护数据一致性。通道互锁机制通道互锁机制被引入以避免死锁，确保了低优先级流不会阻塞高优先级流，从而维护了系统的响应性和吞吐量。系统优化策略系统优化策略包括缓存一致性协议的实现和动态负载均衡算法的应用，这些策略共同提高了系统的整体性能。确保系统能够更有效地管理核心间的工作分配，减少内存访问延迟，并提高计算效率。2.2.3 具体框架在现代计算机系统中，浮点运算单元（Floating Point Unit, FPU）是处理浮点数运算的关键硬件组件。FPU 专门设计用于执行浮点运算，包括加法、减法、乘法、除法以及更复杂的数学函数，如平方根和指数运算。在本次架构中，FPU 与三个 VexRiscv CPU 核心协同工作，形成了一个高效的处理系统。在该架构中，FPU 与 CPU0、CPU1、CPU2 核心相连，通过 Fetch、Decode、Execute 和 Memory 等阶段进行指令的获取、解码、执行和存储。每个 CPU 核心都通过 RF（寄存器文件）与 FPU 交互，实现数据的快速存取。此外，Load、 Store 操作允许 CPU 核心从内存中加载数据或将结果存储回内存。目前该 FPU 还支持高级运算，如 MIN、MAX、SGNJ（符号函数）、FMA（融合乘加）等，这些运算对于科学计算和工程应用至关重要。该三核+FPU 系统较之前的四核系统在拥有了 FPU 单元后使用 FPU 来专门进行浮点运算的处理，可以提供更高的计算精度和效率。在多线程环境中，FPU 能够保证各个线程的浮点运算不会相互干扰，从而提高系统的稳定性和可靠性。在实际应用中，许多程序和算法可能无法充分利用所有核心，三核+FPU 系统通过优化核心与 FPU 的协同工作，可以更有效地处理浮点密集型任务，从而在特定应用场景下实现更高的性能。减少一个核心可以降低整体功耗，这对于移动设备和需要长时间运行的应用尤为重要，故 FPU 的集成有助于在保持性能的同时降低功耗。第三部分 完成情况及性能参数3.1 完成情况：本小组目前的完成情况如表 4
