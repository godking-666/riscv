**★ 接线结论（2026-10-12 已核对）：**
1. **供电**：J17 脚 37/38 = GND、**39/40 = A3V3_3000MA（模组电源输入）**，与 J10 脚 37/38 = GND、39/40 = A3V3 **逐脚对齐，pin-pin 直插即可供电，无短路**。
2. **接法**：J17 ↔ J10 pin 对 pin 直插（模组电源脚位与扩展口电源脚位对齐，即为其设计意图）。
3. **未标脚**：J17 脚 2/15/16/19/28/30/36 为 NC（悬空），对应 J10 侧（A5V0/L25/L24/AA25/R26/N26）留空。
4. **模组 XCLK**：自带 24MHz 晶振，FPGA 无需输出 XCLK（cam_xclk 不接）。
5. **cam_pwdn**：J17 无 PWDN 脚，模组内部处理，demo 端口悬空。
6. 单路上板优先：先接 CAM1（信号在 J17 脚 3-18），RTL 端口不变；双目选路留作后续。

> ★ 优先「单路先上板」（只用一眼做识别，RTL 端口不变），双目选路/立体留作后续。

**方案 B：HDMI 输入（MS7200，板载，暂留备选）** —— 手册 §1.4.2.4（p31-32）

## 3. 跨组影响（同步 CPU 组）

1. **系统时钟**：core_clk 原假设 93.75MHz 失效 → 新板 27MHz 晶振，倍频方案（GPLL）须 CPU 组定案，全 SoC 统一。
2. **DDR3**：板载 2×DDR3（32bit/1066）在 R4/R5 BANK（1.5V）——若 CPU 组用 DDR3 需自建控制器；视觉侧不用。
3. **接口契约不变**：MMIO 总线、寄存器表、地址映射（0x8000_0000 段）与板卡无关，照旧。
4. **图像源变更（OV5640 双目 → 40Pin 扩展口）**：视觉侧输入通路保持 OV5640 DVP（单路先上板），仅引脚绑定到 J10；双目选路/立体为后续增强，接口契约 §9.2 图像通路描述同步修订。
